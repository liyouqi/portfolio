02 / Intelligence layer

Regulatory RAG

Evidence-grounded regulatory question answering.

A good answer is not the starting point. The difficult part is deciding what the question is really asking, finding evidence for each claim and making uncertainty visible.

Break the question apart. Retrieve for each claim. Generate only from evidence.
Demo in progress GitHub profile ↗
  1. 01QuestionWhat is actually being asked?
  2. 02PlanChoose sources and retrieval route.
  3. 03ClaimsSplit multi-part questions.
  4. 04RetrieveCombine lexical and semantic signals.
  5. 05EvidenceBind passages to each claim.
  6. 06AnswerCite—or say what is missing.
